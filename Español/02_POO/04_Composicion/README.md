# Composición

## Qué aprenderás

Un objeto puede contener otro: la relación es «tiene un». El miembro se construye antes del cuerpo del constructor del objeto que lo contiene.

## Analogía

Un automóvil tiene un motor; no es un tipo de motor.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `Motor encendido`.

## Practica

Agrega un método para apagar el motor a través del automóvil.

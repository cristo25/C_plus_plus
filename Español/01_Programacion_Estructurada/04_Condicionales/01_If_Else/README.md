# Decidir con if y else

## Qué aprenderás

Una condición produce `true` o `false`. `if`, `else if` y `else` eligen una rama. Combina condiciones con `&&`, `||` y `!`.

## Analogía

Es una bifurcación: tomas un camino distinto según la señal que encuentras.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `Entrada permitida`.

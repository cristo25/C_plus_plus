# Arreglos

Empieza con un cajón y después con un mueble. El integrador guarda notas en una matriz y sus promedios en un arreglo: `9` y `8`.

## Orden de estudio

1. [Unidimensionales](01_Unidimensionales/README.md)
2. [Matrices](02_Matrices/README.md)

Después, lee y ejecuta el `main.cpp` de **esta carpeta**: reúne lo aprendido en las subcarpetas.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Cada subcarpeta tiene su propio programa. Compila un ejemplo a la vez: todos tienen su propia función `main`.

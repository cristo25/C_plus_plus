# Matrices

## Qué aprenderás

Una matriz tiene filas y columnas. Aquí usamos un `array` de arreglos; ambos índices comienzan en cero.

## Analogía

Un mueble tiene varios cajones (filas) y cada cajón tiene compartimentos (columnas).

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: dos filas, `1 2 3` y `4 5 6`.

## Practica

Calcula la suma de cada fila por separado.

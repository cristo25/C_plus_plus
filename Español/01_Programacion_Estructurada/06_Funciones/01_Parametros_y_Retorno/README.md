# Funciones: parámetros y retorno

## Qué aprenderás

Una función recibe datos, realiza una tarea y puede devolver un resultado. Los parámetros por valor son copias: cambiarlos no modifica el original.

## Analogía

Una máquina recibe ingredientes por una entrada y entrega un producto por la salida.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `16`. Usa números pequeños; un `int` tiene un rango limitado.

## Practica

Crea una función que convierta minutos a segundos.

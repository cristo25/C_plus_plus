# Funciones

Divide un problema en tareas pequeñas. El integrador calcula un subtotal por valor y aplica un cupón por referencia; el total es `50`.

## Orden de estudio

1. [Parámetros y retorno](01_Parametros_y_Retorno/README.md)
2. [Referencias](02_Referencias/README.md)

Después, lee y ejecuta el `main.cpp` de **esta carpeta**: reúne lo aprendido en las subcarpetas.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Cada subcarpeta tiene su propio programa. Compila un ejemplo a la vez: todos tienen su propia función `main`.

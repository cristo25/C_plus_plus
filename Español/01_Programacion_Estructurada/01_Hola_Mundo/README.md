# Tu primer programa

## Qué aprenderás

`#include` incorpora declaraciones de la biblioteca estándar; `main` es el punto de entrada y `cout` escribe en la consola. El programa termina con código 0 cuando todo va bien.

## Analogía

El programa es una receta. `main` indica dónde comienza el cocinero y cada instrucción es un paso.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `Hola, C++!`.

## Practica

Cambia el saludo por tu nombre. Agrega una segunda línea.

# Repetir con do while

## Qué aprenderás

`do while` evalúa la condición después del cuerpo, por lo que siempre ejecuta al menos una vuelta.

## Analogía

Pruebas una llave al menos una vez antes de decidir si necesitas seguir intentando.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: tres líneas, desde `Intento 1` hasta `Intento 3`.

## Practica

Empieza con `intentos = 3` y observa que el cuerpo se ejecuta igualmente.

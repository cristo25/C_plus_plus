# Repetir con for

## Qué aprenderás

`for` reúne inicio, condición y avance. Es apropiado cuando conoces cuántas repeticiones necesitas.

## Analogía

Recorres cinco casilleros, uno por uno, sin saltarte ninguno.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `15`.

## Practica

Imprime la tabla del 7 con un ciclo de diez repeticiones.

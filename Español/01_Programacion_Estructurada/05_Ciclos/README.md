# Ciclos

Compara cuándo se evalúa la condición. El integrador acumula pedidos, los entrega y emite un aviso; produce `6` entregas y `1` aviso.

## Orden de estudio

1. [For](01_For/README.md)
2. [While](02_While/README.md)
3. [Do while](03_Do_While/README.md)

Después, lee y ejecuta el `main.cpp` de **esta carpeta**: reúne lo aprendido en las subcarpetas.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Cada subcarpeta tiene su propio programa. Compila un ejemplo a la vez: todos tienen su propia función `main`.

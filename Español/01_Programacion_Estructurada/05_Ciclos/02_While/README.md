# Repetir con while

## Qué aprenderás

`while` comprueba la condición antes de cada vuelta. Puede ejecutarse cero veces; modifica algo que permita terminar.

## Analogía

Llenas una alcancía mientras no alcanzas la meta.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `4 semanas`.

## Practica

Cambia la meta a 110. Explica por qué el ahorro final es 125.

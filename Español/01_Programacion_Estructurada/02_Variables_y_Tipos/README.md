# Variables, tipos y operadores

## Qué aprenderás

Declara `int`, `double`, `char`, `bool` y `string`. Usa `const` para datos que no cambian. La división entre enteros descarta la parte decimal; convierte un operando a `double` cuando necesites conservarla.

## Analogía

Una variable es una caja etiquetada; su tipo determina qué puede guardar. `const` pone un sello que impide cambiar el contenido.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `Cuaderno: 37.5` y `A disponible: true`.

## Practica

Calcula el precio de cinco productos. Compara `7 / 2` con `7.0 / 2`.

También muestra división entera `2` y decimal `2.5`.

# Integrador: reporte de calificaciones

## Qué aprenderás

Combina funciones, referencias, cadenas, arreglos, ciclos, condiciones, un puntero no propietario y un archivo. Lee el código en orden: calcular, clasificar, construir el reporte y guardarlo.

## Analogía

Un maestro revisa un cajón de notas, calcula un promedio y lo anota en su cuaderno.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `Ana: 9.000000 - Aprobado`. Agrega el reporte a `reporte_demo.txt`.

## Practica

Agrega otro alumno y una función que devuelva la nota más alta. Mantén las notas dentro de 0 a 10.

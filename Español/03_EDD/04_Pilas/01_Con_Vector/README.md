# Una pila con vector

## Qué aprenderás

Una pila sigue LIFO: el último que entra es el primero que sale. `push_back`, `back` y `pop_back` permiten implementarla; comprueba `empty` antes de consultar o sacar.

## Analogía

Una pila de platos: colocas uno arriba y retiras el de arriba.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `Sale: 20`.

## Practica

Agrega tres elementos y retíralos con un ciclo hasta que quede vacía.

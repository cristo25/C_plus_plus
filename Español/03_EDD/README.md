# Estructuras de datos y algoritmos

Elige estructuras según sus operaciones y costos. EDD es un área de estudio que puedes implementar con programación estructurada y POO.

La [guía general](../README.md#estructuras-de-datos-y-algoritmos) presenta todo el bloque con texto y ejemplos de código. Las guías de cada tema comparan variantes; los comentarios de `main.cpp` y los headers explican cada operación junto a su implementación.

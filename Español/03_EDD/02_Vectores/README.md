# Vectores

Estudia tamaño, recorrido, modificación y objetos. El integrador organiza tareas, marca una y la elimina; quedan `Compilar` y `Practicar`.

## Orden de estudio

1. [Crear y recorrer](01_Crear_y_Recorrer/main.cpp)
2. [Insertar y eliminar](02_Insertar_y_Eliminar/main.cpp)
3. [Vector de objetos](03_Vector_de_Objetos/main.cpp)

Después, lee y ejecuta el `main.cpp` de **esta carpeta**: reúne lo aprendido en las subcarpetas.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Cada subcarpeta tiene su propio programa. Compila un ejemplo a la vez: todos tienen su propia función `main`.

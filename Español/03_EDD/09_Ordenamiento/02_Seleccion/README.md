# Selección

## Qué aprenderás

Busca el menor de la zona pendiente y lo intercambia con su primera posición. Tiempo O(n²), incluso si ya estaba ordenado; memoria adicional O(1). No es estable en esta implementación. Lee su función en `../Ordenamientos.h`.

## Analogía

De un montón de cartas tomas siempre la menor y la colocas en la siguiente posición libre.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: `-1 0 3 3 5`.

## Practica

Cuenta comparaciones para cuatro valores y compáralas con burbuja.

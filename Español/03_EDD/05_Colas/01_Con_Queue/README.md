# Cola FIFO

## Qué aprenderás

`queue` atiende en orden de llegada: first in, first out. Agrega con `push`, consulta con `front` y elimina con `pop`. Comprueba `empty` antes de consultar.

## Analogía

La fila de las tortillas: se atiende primero a quien llegó primero.

## Ejecuta el ejemplo

Abre una terminal **en esta carpeta**. Necesitas un compilador compatible con C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o programa.exe
./programa.exe
```

Salida: primero `Atender: Ana`, después `Atender: Luis`.

## Practica

Agrega una tercera persona y verifica el orden.

# Variables, types and operators

## What you will learn

Declare `int`, `double`, `char`, `bool` and `string`. Use `const` for values that do not change. Integer division discards the fractional part; convert an operand to `double` to keep it.

## Analogy

A variable is a labeled box. Its type determines what it can hold. `const` seals its contents.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: `Notebook: 37.5` and `A available: true`.

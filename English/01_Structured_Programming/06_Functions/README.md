# Functions

Split a problem into small tasks. The integration example calculates a subtotal by value and applies a coupon by reference; the total is `50`.

## Study order

1. [Functions: parameters and return values](01_Parameters_and_Return/README.md)
2. [References and parameter passing](02_References/README.md)

After finishing the subfolders, read and run the `main.cpp` **in this folder**. It combines what you learned in the individual lessons.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Every subfolder has its own program. Compile one example at a time: each has its own `main` function.

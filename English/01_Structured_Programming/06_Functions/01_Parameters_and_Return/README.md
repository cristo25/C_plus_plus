# Functions: parameters and return values

## What you will learn

A function receives data, performs a task and may return a result. Parameters passed by value are copies; changing them does not change the original.

## Analogy

A machine receives ingredients through its input and delivers a product through its output.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: `16`. Use small integers: an `int` has a limited range.

# Integration: a grade report

## What you will learn

Combine functions, references, strings, arrays, loops, conditions, a non-owning pointer and a file. Read the steps in order: compute, classify, build the report and save it.

## Analogy

A teacher checks a drawer of grades, calculates an average and records it in a notebook.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: `Ana: 9.000000 - Passed`. Appends the report to `report_demo.txt`.

## Practice

Add another student and a function returning the highest grade. Keep grades between 0 and 10.

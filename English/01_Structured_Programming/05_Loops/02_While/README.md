# Repeating with while

## What you will learn

`while` checks its condition before each iteration. It may run zero times. Change something that eventually makes the condition false.

## Analogy

Keep filling a piggy bank until you reach your savings goal.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: `4 weeks`.

## Practice

Change the goal to 110 and explain why the final balance is 125.

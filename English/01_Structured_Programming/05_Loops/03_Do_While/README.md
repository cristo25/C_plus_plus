# Repeating with do while

## What you will learn

`do while` checks its condition after the body, so it always runs at least once.

## Analogy

Try a key once before deciding whether to keep trying.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: three lines, from `Attempt 1` through `Attempt 3`.

## Practice

Start with `attempts = 3` and observe that the body still runs.

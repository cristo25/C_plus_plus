# Repeating with for

## What you will learn

`for` groups initialization, condition and progress. Use it when you know the number of repetitions.

## Analogy

You visit five lockers one by one without skipping any.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: `15`.

## Practice

Print the multiplication table for 7 with ten iterations.

# Loops

Compare when each loop checks its condition. The integration example accumulates jobs, processes them and issues a notice: `6` deliveries and `1` notice.

## Study order

1. [Repeating with for](01_For/README.md)
2. [Repeating with while](02_While/README.md)
3. [Repeating with do while](03_Do_While/README.md)

After finishing the subfolders, read and run the `main.cpp` **in this folder**. It combines what you learned in the individual lessons.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Every subfolder has its own program. Compile one example at a time: each has its own `main` function.

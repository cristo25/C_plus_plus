# Choosing with switch

## What you will learn

`switch` selects among concrete integer, character or enumeration values. `break` ends a case and `default` handles unknown values. This example uses `return`, which ends both the case and the function.

## Analogy

A numbered restaurant menu sends each choice to a different preparation.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: `Coffee`.

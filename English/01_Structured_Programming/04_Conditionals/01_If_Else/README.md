# Decisions with if and else

## What you will learn

A condition evaluates to `true` or `false`. `if`, `else if` and `else` select a branch. Combine conditions with `&&`, `||` and `!`.

## Analogy

A fork in the road sends you along a different path depending on the sign.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: `Entry allowed`.

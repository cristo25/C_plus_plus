# Matrices

## What you will learn

A matrix has rows and columns. Here an `array` contains arrays; both indices start at zero.

## Analogy

A cabinet has drawers (rows), and each drawer has compartments (columns).

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: two rows, `1 2 3` and `4 5 6`.

## Practice

Compute the sum of each row separately.

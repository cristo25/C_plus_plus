# A stack using vector

## What you will learn

A stack follows LIFO: last in, first out. Use `push_back`, `back` and `pop_back`; check `empty` before accessing or removing a value.

## Analogy

A stack of plates accepts and removes plates at its top.

## Run the example

Open a terminal **in this folder**. Use a compiler supporting C++17.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Output: `Removed: 20`.

## Practice

Push three values and pop them in a loop until the stack is empty.

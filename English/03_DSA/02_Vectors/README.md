# Vectors

Study size, traversal, modification and stored objects. The integration example organizes tasks, completes one and removes it, leaving `Compile` and `Practice`.

## Study order

1. [Creating and traversing a vector](01_Create_and_Traverse/main.cpp)
2. [Inserting and erasing in vectors](02_Insert_and_Erase/main.cpp)
3. [Vectors of objects](03_Vector_of_Objects/main.cpp)

After finishing the subfolders, read and run the `main.cpp` **in this folder**. It combines what you learned in the individual lessons.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Every subfolder has its own program. Compile one example at a time: each has its own `main` function.

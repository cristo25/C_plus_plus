# Searching

Search first without ordering, then after sorting. The integration example compares both searches on sorted values and shows the original index of 8 changing from 0 to 4.

## Study order

1. [Linear search](01_Linear_Search/README.md)
2. [Binary search](02_Binary_Search/README.md)

After finishing the subfolders, read and run the `main.cpp` **in this folder**. It combines what you learned in the individual lessons.

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o program.exe
./program.exe
```

Every subfolder has its own program. Compile one example at a time: each has its own `main` function.

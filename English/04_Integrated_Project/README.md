# Integrated project — we will develop it later

Here we will build **one program**, separated into headers and implementation files, that applies the previous three blocks. Only its structure and goals exist for now; there is no `main.cpp` or implemented application yet.

```text
04_Integrated_Project/
├── include/   Declarations (.h): models, structures and data access
├── src/       Implementations (.cpp) and the future main.cpp
└── data/      Files used by the program
```

## What we will apply

- Functions, input validation, files and error handling.
- Classes, encapsulation, composition and RAII resource ownership.
- Inheritance and polymorphism when the problem has real variants.
- Vectors, lists, stacks, queues, trees and graphs as the project's operations require.
- Sorting, searching and an explanation of their costs.
- DAO to centralize queries and persistence.
- Separation of headers, implementations and the entry point.

When we resume this block, we will choose a concrete problem and build the application in stages. Earlier integration exercises are complete demonstrations; this will be the combined application.
